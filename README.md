# CS 465 — Module Two: MVC Routing

This project builds on the user's Module One Travlr Getaways website. It adds Express routes/controllers, Handlebars views and header/footer partials, while retaining the existing static pages and images.

## Run on Windows (VS Code terminal)

1. Unzip this folder and open `CS465_Module2_MVC_Routing` in VS Code.
2. Run `npm install` (requires internet the first time).
3. Run `npm start`.
4. Open `http://localhost:3000/travel` to test the Handlebars MVC travel page.
5. Open `http://localhost:3000/` for the Handlebars home page.
6. Run `npm test` to check routes, rendered header/footer, and static assets.
7. Stop the server with Ctrl+C.

## MVC flow

`app.js` → `app_server/routes/travel.js` → `app_server/controllers/travel.js` → `app_server/views/travel.hbs` → `partials/header.hbs` and `partials/footer.hbs`.

The `public/travel.html` original is intentionally retained for comparison with the dynamically rendered `/travel` route. Dynamic trip data using JSON is the next module, not required in Module Two.
